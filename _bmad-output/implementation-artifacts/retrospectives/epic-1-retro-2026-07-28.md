## What Needs Improvement

- **No test coverage.** Epic 1 had zero automated tests. Frontend `npm run test` was a no-op echo. Backend had pytest wired unused.
- **Tracking hygiene.** sprint-status not updated to reflect actual merge state. Stories 1.1–1.4 never promoted past `draft`.
- **Story-record inconsistency.** 1.5–1.8 have Dev Notes + File List + Change Log; 1.1–1.4 have AC only. No Code Review/Testing/Lessons sections in any story.
- **No documented reviews.** `review` frontmatter status on 1.5–1.8 not backed by actual review records.
- **Architecture drift (1.6).** AC required PostgreSQL `wilayas` table seeded via migration; shipped as static TS file. Deferred to Epic 3 planning.
- **Email foundation incomplete.** Celery `send_*` tasks are stubs; no SMTP provider wired; end-to-end path untested. Blocking for Epic 2 (2.2 verification, 2.4 password reset).

## Patterns

- **Root cause: no QA owner.** Zero QA persona in the roster → no quality record → fiction status → no accountability for architectural drift or test gaps.
- **Status-as-vibe.** "Done" meant "code merged" not "verified, tested, and reviewed."
